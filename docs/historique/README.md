# Archives de conception

Ce dossier conserve les documents de conception et d'audit écrits pendant les premiers jalons de DevEye (juin et juillet 2026). Ils sont gardés **tels quels**, pour l'historique des choix et des constats.

**Statut : archives non normatives.**

- Ils ne décrivent pas l'état actuel du projet : les chiffres (nombre d'outils, de constats, de jalons), les chemins, les noms de projets et les plans qu'ils citent sont ceux de l'époque, et beaucoup ont changé ou été abandonnés.
- Ils citent légitimement les applications consommatrices de l'époque ; DevEye lui-même ne dépend d'aucune application cliente (ADR-0013).
- Les références à jour sont : [`README.md`](../../README.md), [`usage.md`](../usage.md), [`architecture.md`](../architecture.md), [`wire-protocol.md`](../wire-protocol.md), [`stability.md`](../stability.md) et les décisions consignées dans [`docs/adr/`](../adr/README.md).
- Ces fichiers ne sont pas relus ni corrigés : en cas de désaccord avec une référence à jour, c'est la référence qui a raison.
